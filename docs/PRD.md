# PRD — 카페 메뉴판 (Excel 구동)

> Product Requirements Document. **무엇을, 왜** 만드는가. 기술 설계는
> [TRD.md](TRD.md)를 본다.

## 1. 배경 / 문제

카페 점주는 메뉴·가격을 자주 바꾸지만, 그때마다 디자인 툴이나 개발자를 거치는
것은 비싸고 느리다. 점주가 이미 익숙한 도구는 **Excel**이다.

이 제품은 점주가 **Excel만 다루면** 매장 디스플레이(태블릿·키오스크·모니터)의
메뉴판이 자동으로 갱신되게 한다. 코드를 모르는 사람도 운영할 수 있어야 한다.

이 프로젝트는 동시에 강의 앵커 예제다. 전달하는 원칙: **데이터(Excel)와
표현(테마/템플릿)의 분리**.

## 2. 목표 / 비목표

### 목표

- 점주가 Excel을 수정·저장하면 화면이 **즉시(수초 내)** 갱신된다.
- 코드 수정 없이 Excel 값만으로 **매장명·테마·페이지 자동전환**을 바꾼다.
- 같은 데이터에 **테마만 교체**해 전혀 다른 디자인을 낸다.
- 디바이스(모바일/태블릿/사이니지)에 맞는 반응형 화면을 제공한다.

### 비목표 (이번 범위 아님)

- 메뉴 편집 UI(웹에서 직접 입력) — 편집은 Excel이 담당.
- 다중 매장 계정/인증/결제.
- 주문·POS 연동.
- 실시간 양방향 통신(화면은 읽기 전용 표시).

## 3. 사용자 / 시나리오

| 사용자    | 시나리오                                                                     |
| --------- | ---------------------------------------------------------------------------- |
| 카페 점주 | Excel에서 아메리카노 가격을 4500→5000으로 바꾸고 저장 → 매장 모니터가 갱신됨 |
| 점주      | `_설정` 시트의 `테마`를 `cafe-dark`→`bistro-light`로 바꿈 → 디자인 전체 교체 |
| 점주      | 시트 탭 "신메뉴" 추가 → 메뉴판 페이지가 자동으로 한 장 늘어남                |
| 손님      | 키오스크에서 `자동전환초`마다 페이지가 순환되는 메뉴판을 봄                  |

## 4. 기능 요구사항

### F1. Excel → 메뉴판 매핑

- 시트(탭) 1개 = 메뉴판 페이지 1개. 시트 이름 = 페이지 이름.
- `_` 언더스코어로 시작하는 시트는 페이지에서 **제외**(설정용).
- 첫 행은 헤더: `메뉴명 | 가격 | 설명 | 품절 | 카테고리`.

### F2. 자동 갱신

- 점주가 `menu.xlsx`를 **저장**하면 화면이 자동 갱신된다.
- 값을 바꿔도 **저장 전까지는 반영되지 않는다**(로컬 .xlsx는 저장 시점에 디스크
  기록). 이 동작은 의도된 것이며 사용자에게 안내한다.

### F3. 데이터 표시 규칙

- **가격**: Excel엔 숫자만. 화면에서 `원` 및 천단위 표시.
- **품절**: `Y`이면 취소선 + 흐림 + "품절" 라벨. 빈칸이면 정상.
- **카테고리**: 한 페이지 안에서 소제목 그룹으로 묶을 수 있다.

### F4. `_설정` 시트

| 항목       | 값 예시   | 의미                                    |
| ---------- | --------- | --------------------------------------- |
| 매장명     | 빌런 커피 | 헤더에 표시                             |
| 테마       | cafe-dark | 디자인 세트 선택                        |
| 자동전환초 | 0         | 0=수동, 양수=그 초마다 페이지 자동 전환 |

### F5. 테마 시스템

- 테마 8종: `beige`, `bistro-light`, `cafe-dark`, `cream`, `deep-green`,
  `forest-dark`, `forest-light`, `light-olive`.
- 테마 교체는 **CSS + 배경/테두리 PNG 세트 교체**만으로 이뤄진다(데이터 불변).

### F6. 반응형 / 디바이스

- 디바이스 4종 최적화: `mobile`, `tablet-port`, `tablet-land`, `signage`.
- 디바이스별 배경·프레임 PNG가 분리되어 있다.

## 5. 성공 기준 (수용 조건)

- [ ] Excel 저장 후 **3초 이내** 화면 갱신.
- [ ] `_설정`의 `테마` 변경만으로 코드 수정 없이 디자인이 바뀐다.
- [ ] 시트 추가/삭제가 페이지 수에 즉시 반영된다.
- [ ] `품절=Y` 항목이 시각적으로 명확히 구분된다.
- [ ] 4개 디바이스 폭에서 레이아웃이 깨지지 않는다.

## 6. 열린 질문

- 가격 천단위 콤마 표시 여부(예: `5,000원`)?
- 빈 시트/잘못된 헤더일 때 화면 처리(에러 표시 vs 무시)?
- 다중 클라이언트 동시 접속 시 자동전환 동기화 필요 여부?
